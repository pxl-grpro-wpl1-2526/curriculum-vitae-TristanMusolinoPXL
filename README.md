# Online Curriculum Vitae — Werkplekleren 1

Dit project is een online curriculum vitae, ontwikkeld als opdracht voor het vak **Werkplekleren 1** binnen de opleiding **Graduaat Programmeren** aan **Hogeschool PXL**. Het doel van deze opdracht is het demonstreren van vaardigheden in semantische HTML5, CSS3-styling en responsive design zonder gebruik te maken van externe libraries of frameworks.

## 🚀 Functionaliteiten (WEB-ID's)

In dit project zijn de volgende functionele vereisten geïmplementeerd:

* **WEB-01:** Alle vereiste inhoud (Intro, Foto, Diploma's, Vaardigheden, Talen en Werkervaring) is aanwezig.
* **WEB-02:** Hover-effect (schaduw) op de profielfoto.
* **WEB-03:** Klikbare profielfoto die linkt naar LinkedIn in een nieuw tabblad.
* **WEB-04:** Talenkennis weergegeven in een tabel met afwisselend gestylede rijen (`zebra-striping`).
* **WEB-05:** Werkervaring gepresenteerd in een overzichtelijke lijst met functie, organisatie, periode en omschrijving.
* **WEB-06:** Footer met naam, klas, opdrachtbeschrijving en een "Terug naar boven"-knop.
* **WEB-07:** Werkende "Terug naar boven"-functionaliteit via interne links.
* **WEB-08:** Gebruik van subtiele animaties, hover-effecten en professionele typografie.
* **WEB-09/10:** Document opgesteld in het Nederlands met een consistent gebruik van kleuren en lettertypes.
* **WEB-11:** Responsive layout waarbij elementen automatisch onder elkaar plaatsen op kleinere schermen.
* **WEB-12:** Specifieke mobiele layout voor de talensectie waarbij de tabel transformeert naar een alternatieve weergave voor betere leesbaarheid.
* **WEB-13:** Media queries toegepast voor Mobiel (< 576px), Tablet (576px - 992px) en Desktop (>= 992px).

## 🛠️ Technische Details

* **HTML5:** Gebruik van semantische elementen zoals `<nav>`, `<main>`, `<section>`, `<figure>` en `<footer>`.
* **CSS3:** Volledig op maat gemaakte styling in een apart bestand (`style.css`), inclusief:
    * Flexbox en Grid layouts.
    * Custom sliders voor technische vaardigheden.
    * Responsive tabel-logica.
* **Geen Frameworks:** Er is geen gebruik gemaakt van Bootstrap, Tailwind of andere CSS-libraries.
